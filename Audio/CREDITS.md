# Звуки и музыка

Все файлы в `Audio/music/` и `Audio/sfx/` сделаны специально для Hobbie: синтезированы скриптом `Audio/tools/synth.py` (numpy и ffmpeg), без сэмплов и чужих записей. Права принадлежат автору проекта, коммерческий релиз разрешён без ограничений.

Пересобрать все звуки или часть из них (из корня репозитория):

```
python3 Audio/tools/synth.py
python3 Audio/tools/synth.py chop village_theme
```
