# Генератор спрайтов

Вся графика в `Art/` нарисована этим генератором: модели собираются из простых объёмных фигур, рендерятся сверху под углом и сохраняются как pixel art с контуром. Чужих ассетов нет, лицензии не нужны.

## Запуск

Нужны Python 3, numpy и Pillow.

```
cd tools/sprites
python3 build.py                      # всё
python3 build.py hero mobs giant      # отдельные цели
python3 build.py buildings:house,farm # только перечисленные здания
python3 build.py giant:death          # одна анимация, остальные берутся из готовых листов
```

Цели: `hero`, `mobs`, `giant`, `beam`, `buildings`, `weapons`, `pickups`, `resources`. Персонажи рендерятся долго (гигант около 8 минут), остальное за секунды.

Скрипт сам пишет `.png`, `.import` и `SpriteFrames` (`.tres`). `uid` берётся из пути файла, поэтому при перегенерации ссылки в сценах не ломаются.

## Файлы

| Файл | Что внутри |
|---|---|
| `sdf.py` | Рендер: примитивы, камера, свет, заливка палитрой, контур. |
| `palette.py` | Материалы: палитра из 4–5 оттенков и цвет контура. |
| `kit.py` | Сборка моделей и текстуры (доски, кирпич, черепица, солома, камень). |
| `rig.py`, `humanoid.py` | Скелет человечка и анимации: стойка, ходьба, удар, работа, лук, смерть. |
| `hero.py`, `mobs.py`, `beasts.py`, `giant.py` | Герой, гоблин, орк, скелет-лучник, волк, каменный гигант. |
| `buildings.py` | Здания по уровням. |
| `items.py`, `resources.py`, `effects.py` | Оружие, стрела, монеты, артефакт, ресурсы, луч гиганта. |
| `godot_res.py`, `build.py` | Запись ресурсов Godot и цели сборки. |
| `preview.py` | Склейка кадров в одну картинку для просмотра. |

## Как добавить

- Новый моб-человечек: класс `Spec` в `mobs.py` (пропорции, материалы, детали головы и тела) и экземпляр `Mob` со словарём анимаций, затем строка в `MOBS` в `build.py`.
- Новое здание: функция в `buildings.py`, которая возвращает `Kit`, и запись в `BUILDINGS` (размер в клетках и список уровней).
- Новое оружие или предмет: функция в `items.py` и запись в `WEAPONS` или `PICKUPS`.
